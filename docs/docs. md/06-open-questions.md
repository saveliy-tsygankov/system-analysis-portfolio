# 6. Открытые вопросы к заказчику

| № | Вопрос | На что влияет |
| --- | --- | --- |
| 1 | Сколько залов в студии | При нескольких залах нужна сущность «Зал», а FR-6 проверяет занятость зала |
| 2 | Длительность каждой услуги, рабочие часы студии, минимальный срок записи | FR-5, FR-6, НФ-1 |
| 3 | Шаг сетки слотов (30 минут?) и горизонт записи (60 дней?) | FR-13, метод GET /photographers/{id}/slots |
| 4 | Срок отмены (24 часа?) и правила переноса записи | FR-16, ВИ-8 |
| 5 | Нужны ли иностранные номера телефонов | FR-3 |
| 6 | Посещаемость соцсетей студии в сутки | Расчёт нагрузки, НФ-1, НФ-2, НФ-4 |
| 7 | Бюджет на хостинг и поддержку, есть ли ночное дежурство подрядчика | НФ-5, НФ-6 |
| 8 | Зарегистрирован ли оператор персональных данных в реестре Роскомнадзора | НФ-11 |
| 9 | Нужен ли вариант «любой свободный фотограф» | Сейчас фотограф выбирается обязательно, поэтому БЦ-4 выполняется автоматически; новый вариант потребует пересмотра БЦ-4, FR и API |

## Границы документации

В проект не вошли сценарии ВИ-7, ВИ-8 и ВИ-10–ВИ-14, методы админ-панели и метод переноса записи: они описываются по тем же правилам в следующей итерации.
