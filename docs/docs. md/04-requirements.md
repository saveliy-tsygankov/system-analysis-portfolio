# 4. Функциональные и нефункциональные требования

Требования выведены из шагов сценариев UC-4 и ВИ-7 и из бизнес-целей. Каждое функциональное требование атомарно, проверяемо и ссылается на источник. Все требования обязательны для MVP. Значения с пометкой «допущение» подтверждаются заказчиком.

## 4.1 Функциональные требования

| ID | Требование | Источник |
| --- | --- | --- |
| FR-1 | Система требует заполнить имя, телефон, email и согласие на обработку персональных данных | UC-4, шаги 8–10 |
| FR-2 | Имя содержит 2–50 символов: буквы кириллицы и латиницы, пробел, дефис, апостроф | UC-4, шаг 10 |
| FR-3 | Телефон после удаления пробелов, скобок и дефисов начинается с «+7» или «8» и содержит ровно 10 цифр после префикса (допущение: только номера РФ) | UC-4, шаг 10 |
| FR-4 | Email содержит ровно один «@», непустую часть до него, домен с точкой, не содержит пробелов и не длиннее 254 символов | UC-4, шаг 10 |
| FR-5 | Время начала записи лежит в рабочих часах студии и не раньше чем через 2 часа от текущего момента (допущение) | UC-4, шаг 10 |
| FR-6 | Выбранный фотограф свободен весь интервал, равный длительности услуги | UC-4, шаг 10 |
| FR-7 | Проверка по FR-6 и закрепление времени выполняются одной неделимой операцией | UC-4, шаг 11 |
| FR-8 | Если любая проверка не пройдена, запись не создаётся и время не закрепляется | UC-4, 4.E1–4.E3 |
| FR-9 | Проверки FR-1–FR-6 выполняются на сервере независимо от браузера | UC-4, шаг 10 |
| FR-10 | Для каждого неверного поля система показывает сообщение об ошибке и сохраняет введённые значения | UC-4, 4.E1 |
| FR-11 | Если время занято, система показывает другие свободные слоты этого фотографа и сохраняет контакты | UC-4, 4.E2 |
| FR-12 | Свободные слоты рассчитываются как рабочие интервалы фотографа минус записи не в статусе «Отменена»; слот лежит целиком внутри интервала и длится как услуга | UC-4, шаг 5 |
| FR-13 | Начала слотов идут с шагом 30 минут (допущение) | UC-4, шаг 5 |
| FR-14 | Слоты, начинающиеся раньше чем через 2 часа от текущего момента, система не показывает | UC-4, шаг 5; FR-5 |
| FR-15 | Клиент отменяет запись по секретной ссылке из уведомления; без неё отмена невозможна | ВИ-7 |
| FR-16 | Отмена возможна не позднее чем за 24 часа до начала (допущение); при отмене время освобождается | ВИ-7 |

## 4.3 Расчёт нагрузки (допущение)

Худший случай: все 500 записей в месяц приходят с сайта. При конверсии посетителя в запись 3% это около 16 700 визитов в месяц, около 560 в сутки. В пиковый час приходится 15% суточных визитов (около 84), при сессии 5 минут одновременно на сайте около 7 человек. С запасом ×10 на рекламные всплески расчёт округлён до 100 одновременных пользователей; это основание для НФ-1, НФ-2 и НФ-4.
