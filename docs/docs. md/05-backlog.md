# 5. Декомпозиция задач для разработки

История UC-4 «Записаться на съёмку» (основной поток и ветки 4.E1–4.E3, без ветки с пожеланиями 4.1) разбита на 14 задач общим объёмом 60 SP. Оценка в стори-поинтах по шкале Фибоначчи, мощность команды 30 SP за спринт (допущение). Самая крупная задача оценена в 5 SP, задач на 8 SP и больше нет.

Фронтенд во втором спринте может начать работу на заглушках, пока бэкенд не готов, потому что контракт API согласован заранее ([api/openapi.yaml](../api/openapi.yaml)). Невидимая работа выделена отдельными задачами: начальные данные (1), идемпотентность (7), автотесты (12), нагрузка (13), безопасность и резервные копии (14). Остальные варианты использования (ВИ-7–ВИ-14, ВИ-16, ветка 4.1) остаются в бэклоге.
