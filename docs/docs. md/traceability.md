# Матрица трассируемости

Каждая бизнес-цель доходит до задач для разработки. По матрице видно, откуда взялась любая задача и какой цели она служит.

| Цель | Варианты использования | Требования | Данные | API | Задачи |
| --- | --- | --- | --- | --- | --- |
| БЦ-1: не менее 50% записей через сайт | ВИ-4, ВИ-11, ВИ-16 | FR-1–FR-11, НФ-7 | bookings.channel | POST /bookings | 6, 11 |
| БЦ-2: рост с 250 до 500 записей в месяц | ВИ-4, ВИ-7, ВИ-16 | FR-12–FR-16, НФ-4, НФ-5 | bookings.created_at | Все методы | 4, 6, 14 |
| БЦ-3: запись не дольше 3 минут, 70% доводят до конца | ВИ-4 | FR-9–FR-11, НФ-1, НФ-2, НФ-7 | bookings | GET slots, POST /bookings | 4, 6, 10, 11, 13 |
| БЦ-4: 70% онлайн-записей с выбором фотографа | ВИ-2, ВИ-4 | НФ-3 | photographers, portfolio_works | GET /photographers | 3, 10 |

## Пример сквозной цепочки: задача 6

БЦ-3 (запись за 3 минуты без ошибок) → UC-4 шаги 10–11 → FR-6, FR-7, FR-8 → таблицы `bookings`, `clients`, `consents`, ограничение `bookings_no_overlap` ([database/01_schema.sql](../database/01_schema.sql)) → метод `POST /bookings` ([api/openapi.yaml](../api/openapi.yaml)) → НФ-12 (тест двух одновременных запросов, [database/04_double_booking_test.sql](../database/04_double_booking_test.sql)).
